# 👩‍💻 My-Website

A simple personal landing page introducing myself — built as a small first project while learning HTML & CSS.

🔗 The card shares a bit about who I am, what I'm currently learning, and links straight to my GitHub profile.

---

## ✨ Features

- 🎨 **Clean, Centered Card Layout** — A minimal profile card centered on a pastel green background.
- 🖼️ **Profile Photo** — Displays a profile picture.
- 📝 **Short Bio & Tagline** — A quick intro: CS student learning programming & DSA, practicing on LeetCode, and exploring AI.
- 🔘 **Call-to-Action Button** — A styled button linking directly to my [GitHub profile](https://github.com/akhithasvijayan).

---

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (flexbox, custom colors, hover transitions) |

No frameworks, build tools, or JavaScript — just a static HTML + CSS page.

## 🚀 Getting Started

Since this is a static site, no installation is required.

```bash
git clone https://github.com/akhithasvijayan/My-Website.git
cd My-Website
```

Open `index.html` directly in a browser, or serve it locally:

```bash
# Python
python -m http.server 8000

# or Node
npx serve .
```

Then visit `http://localhost:8000`.
